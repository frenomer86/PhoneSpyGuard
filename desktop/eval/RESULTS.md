# Desktop detection evaluation

Generated by `cargo test -p psg-windows --test evaluation` with `PSG_WRITE_EVAL=1`, from the signed rule bundle in `rules/`. These are synthetic inventories: they measure the matching and scoring rules, not the Windows collectors and not real malware on real PCs. The spec's full evaluation (real stalkerware families, the Play top 500 on phones, MVT test material) still has to be run on devices.

Read the known-product row with care: the product names below were written by the same person who wrote the indicator lists, so 100% shows that matching works on names as installers record them, not that the lists cover every product. The first run of this evaluation flagged two common programs (Radmin VPN, and a game whose publisher name contains the letters of Atera); both were fixed by matching publishers at word starts and narrowing the Radmin token, and the set is kept so they stay fixed.

The known limit is real: a signed commercial monitoring product that is not on the list, installed in Program Files and doing nothing else unusual, looks like any other program. Only the indicator list, a hash match, or the camera/microphone and network records catch it. Keeping the list current matters as much as the rules.
