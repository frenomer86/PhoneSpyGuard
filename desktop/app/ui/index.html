Things you said you set up

Detection rules

To install from files, choose both desktop-bundle.json and desktop-bundle.sig.json together. They are checked exactly like a download: two of the three release keys must have signed them, and they must be newer than the rules in use.

What this app can and can't do

  • It only reads this PC. It never installs a driver, never changes settings on its own, and only asks for administrator rights for the deep check you start.
  • It never sends your findings, timeline, messages or answers anywhere. Its only network use is downloading rule updates, which sends nothing about you; the update server can see this PC's internet address, as any website can. If your network may be watched, turn automatic rules off and install rule files instead.
  • Detection rules are used only if two of three release keys signed them; compare the rules' fingerprint above with the public rule log.
  • Answers that lower a finding ("I set this up", turning the watch off) need Windows Hello or your password, and are written to the timeline. Someone who knows your PIN or password can still give them.
  • It has no feature to watch anyone else. It checks the PC it runs on, for the person who uses it.
